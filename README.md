# Sistema de Gestão Financeira

## Sobre o Projeto

Esta proposta está sendo desenvolvida como parte de um projeto da faculdade UnB(Gama)

O objetivo é criar um **Sistema de Gestão Financeira** capaz de auxiliar usuários no controle de suas finanças pessoais, permitindo o gerenciamento de receitas, despesas, saldo e outras funcionalidades relacionadas à organização financeira.

## Desenvolvedores

- Gabriel Escramin
- Mateus Fernandes

## Objetivos

O sistema busca oferecer recursos como:

- Registro de receitas;
- Registro de despesas;
- Consulta de saldo;
- Histórico de transações;
- Relatórios financeiros;
- Organização e controle das finanças pessoais.

## Status do Projeto

🚧 Em desenvolvimento

O projeto encontra-se em fase de desenvolvimento e novas funcionalidades serão adicionadas ao longo da disciplina.
